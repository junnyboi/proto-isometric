# Gathering and farming concept designs

These three concept designs were generated with **GPT Image 2** on 27 August 2026 for the Protos Harvest gathering and farming proposal. The existing Starbloom crop sheet and woodland broadleaf tree were used as style references. Prompts required grounded photoreal botanical rendering, warm woodland light, a readable 90 × 45 isometric perspective, Protos' industrial caretaker identity, and no UI text or logos.

# Pickup VFX Sources

`worm_core.png` is an optimized runtime derivative generated with **GPT Image 2** for Walker's Wake on 2026-08-18. The source prompt requested a transparent 2:1 isometric sandworm Core with an amber center, teal circuitry, dark shell, and small salvage fragments. The retained derivative was chroma-cleaned, tightly cropped, and downscaled to 192×192 RGBA; generation masters are intentionally excluded from Git.

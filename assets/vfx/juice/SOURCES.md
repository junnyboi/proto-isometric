# Game Juice VFX Sources

The five runtime PNGs in this directory were generated for Walker’s Wake with **GPT Image 2** on 2026-08-20. The approved Walker’s Wake gameplay target and Impact Run concept were used as visual references. Source generations used a temporary magenta background with background removal; deterministic post-processing removed residual magenta spill, trimmed transparent bounds, resized the assets, and converted `footstep_dust.png` to a neutral grayscale tint mask.

The runtime derivatives are `impact_contact.png`, `footstep_dust.png`, `charge_ready.png`, `relay_flare.png`, and `pickup_spark.png`. Generation masters remain outside Git because the project keeps only accepted runtime derivatives.

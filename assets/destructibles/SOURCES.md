# Biome Destructible Asset Sources

The six runtime sprites in this directory were generated for Walker’s Wake with **GPT Image 2** on 2026-08-20 using the project’s approved wetland, frozen-tundra, lava-field, and gameplay concept images as style and projection references.

The accepted runtime derivatives are 256×256 RGBA PNG files. Generated masters were alpha-cleaned, trimmed without cropping the subject, resized with Lanczos resampling, and kept outside the repository. No external third-party art was incorporated.

| Runtime asset | Subject |
|---|---|
| `wetland_mangrove.png` | Dead mangrove snag |
| `wetland_stump.png` | Rotting wetland stump |
| `frozen_snow_rock.png` | Snow-capped granite boulder |
| `frozen_pine.png` | Wind-bent frozen pine |
| `lava_basalt_chimney.png` | Columnar basalt chimney |
| `lava_obsidian_cluster.png` | Obsidian clinker cluster |

# Protos Harvest livestock runtime sources

Mossback Grazer, Coilhen, and Rustsnout Rooter anchors were generated with **GPT Image 2** on 2026-08-25 in a locked elevated-isometric view against hot pink. Each anchor drove a six-second zero-camera-motion video carrier with one contained idle/action cycle. A deterministic extractor sampled eight frames, removed border-connected chroma and orphan artifacts, lower-center aligned the silhouettes, and packed each runtime sheet as 4×2 cells of 256×256 RGBA. Raw anchors and carriers remain outside Git.

# Game typography sources

ManusCC0 Regular/Medium/Bold supplies English and Latin text. ManusCC0 Sans CJK SC supplies the shared 6,547-codepoint Simplified Chinese fallback. Both generated packs are CC0-1.0 and need no attribution or delivered notices. `cjk-font.json` pins the Chinese source bytes; `cjk-codepoints.json` pins coverage. The lightweight loader derives from this same font through `tools/prepare_web_shell.py`. Optional CC0 license files accompany the fonts.

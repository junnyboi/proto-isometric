# Runtime font source

`NotoSansCJKsc-ProtoIsometric.otf` is a glyph-subset derivative of **Noto Sans CJK SC Medium**, generated with fonttools `pyftsubset` for the English and Simplified Chinese strings shipped by Proto Isometric.

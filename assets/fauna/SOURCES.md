# Peaceful herd fauna runtime sources

`dune_grazer.png`, `reedback.png`, `rimehorn.png`, and `ember_ram.png` were generated with **GPT Image 2** on 2026-08-20 as original peaceful biome-native herd creatures for Walker's Wake. The accepted 1920×1920 transparent masters remain outside Git. Deterministic key-color removal, alpha cleanup, complete-silhouette trimming, and Lanczos downsampling produced centered 512×512 RGBA runtime sprites. Runtime horizontal flipping, bounce motion, flocking, avoidance, combat targeting, and resource rewards are deterministic Godot behavior; no creature graphics are drawn procedurally.

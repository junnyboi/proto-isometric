# Ancient Outpost Asset Sources

The five runtime PNGs in this directory were generated for **Walker’s Wake** with **GPT Image 2** on August 21, 2026. Prompts requested individual photorealistic horror-eldritch structures in the project’s exact 2:1 isometric perspective, using a temporary pure-magenta background for removal and the approved gameplay/outpost concepts as visual references.

The accepted generations were deterministically keyed to remove residual magenta, trimmed without cutting the architecture, proportionally downscaled, and bottom-aligned on transparent 384×384 canvases. Only these optimized runtime derivatives are kept in source control.

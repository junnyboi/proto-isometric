# Refit Module Icon Sources

`ram_plating.png`, `aftershock.png`, and `storm_seal.png` are accepted runtime derivatives generated with **GPT Image 2** for Walker's Wake. The 1920×1920 generation outputs were deterministically chroma-cleaned, alpha-cropped, square-padded, and downscaled to 128×128 RGBA PNG. Only these optimized runtime derivatives are retained in source control.
